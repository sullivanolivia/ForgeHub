# ForgeHub

ForgeHub enables real-time data processing and event-driven architecture across cross-platform environments through a centralized orchestrator and controller.

ForgeHub is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ForgeHub.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ForgeHub is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
